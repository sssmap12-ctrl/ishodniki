# 📱 Инструкция по сборке APK (Android) и запуску на ПК (Electron)

В ваш проект добавлены все необходимые файлы конфигураций (`package.json`, `capacitor.config.json`, `electron.js`). Вот пошаговая инструкция, как собрать готовую игру.

---

## 🛠️ Подготовка окружения (один раз)

Для сборки вам понадобятся:
1. **Node.js** (скачайте и установите актуальную версию LTS с [nodejs.org](https://nodejs.org/)).
2. **Android Studio** (скачайте и установите с [developer.android.com](https://developer.android.com/studio) для компиляции APK).
3. Откройте терминал/командную строку (PowerShell / cmd) в папке вашего проекта (`c:\Users\sss\Desktop\chat\`) и установите зависимости одной командой:
   ```bash
   npm install
   ```

---

## 🤖 Как собрать APK для Android

Мы используем официальный и современный фреймворк **Capacitor** от команды Ionic. 

Выполните следующие простые команды в терминале проекта:

### Шаг 1: Инициализация Android-платформы (только при первой сборке)
```bash
npm run android-init
```
Затем добавьте модуль Android в проект:
```bash
npm run android-add
```

### Шаг 2: Синхронизация файлов сайта с мобильным проектом
Запускайте эту команду каждый раз, когда вы вносите любые изменения в код сайта (HTML, CSS, JS):
```bash
npm run android-sync
```
*(При запуске этой команды также **автоматически генерируется и устанавливается аватарка приложения** из файла `photo/easy/1.jpg` во всех разрешениях для телефона!)*

### Шаг 3: Компиляция APK в Android Studio (Через интерфейс)
Запустите команду, которая автоматически откроет ваш мобильный проект в установленной Android Studio:
```bash
npm run android-open
```
*Когда Android Studio откроется и завершит индексацию (загрузку Gradle в правом нижнем углу):*
1. В верхнем меню выберите: **Build** ➡️ **Build Bundle(s) / APK(s)** ➡️ **Build APK(s)**.
2. Android Studio скомпилирует проект за пару минут. По завершении в правом нижнем углу появится уведомление со ссылкой **locate** — нажмите на неё, чтобы открыть папку с вашим готовым установочным файлом **app-debug.apk**! Скопируйте его на телефон и устанавливайте!

---

### 🔥 Альтернативный Шаг 3: Компиляция APK напрямую в Командной строке (Без запуска Android Studio UI!)
Если вы хотите собрать APK чисто через консоль, введите одну команду:
```bash
npm run android-build
```
Эта команда автоматически соберет проект, запустит компилятор Gradle и сделает готовый APK!

*По завершении компиляции ваш готовый файл **app-debug.apk** будет лежать по адресу:*
`c:\Users\sss\Desktop\chat\android\app\build\outputs\apk\debug\app-debug.apk`

*(Примечание: Для работы консольной сборки в вашей системе должен быть установлен Java Development Kit (JDK) 17 и прописана переменная окружения `JAVA_HOME`).*

## 💻 Как запустить/собрать версию для ПК (Electron)

Чтобы запустить игру как отдельный десктопный клиент (в красивом мобильном окне на ПК), выполните в терминале команду:
```bash
npm run start-pc
```
*(Для создания `.exe` установщика для ПК можно установить модуль `electron-builder` командой `npm run build-pc`).*
